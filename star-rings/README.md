# 星环秘仪 · Epicycle

一个把**傅立叶变换**藏进占星玩法里的网页解谜游戏（Vite + TypeScript，无框架）。玩家全程接触不到任何数学术语——直到通关后解锁的「秘仪的真相」。

## 开发与运行

```bash
npm install     # 安装依赖（vite + typescript）
npm run dev     # 开发服务器（默认 http://localhost:5173）
npm run build   # tsc 类型检查 + 产物构建到 dist/
npm run preview # 预览构建产物
```

> 注：本机沙盒内 `bun install` 有 tempdir 限制，故使用 npm（已验证）；在正常终端里用 bun 亦可。

## 结构

- `index.html` —— 入口页（Vite 根）
- `src/game.ts` —— 关卡定义、DFT 目标构建、状态与评分（核心算法）
- `src/render.ts` —— Canvas 渲染（星空/星图/符环/轨迹/粒子）
- `src/ui.ts` —— 面板 DOM（转盘/滑块/探测/图鉴/覆盖层）
- `src/main.ts` —— 装配、主循环、评分调度
- `src/audio.ts` —— WebAudio 琶音与轻响
- `legacy/singlefile.html` —— 早期的单文件原型（存档）

## 玩法

- 每关展示一幅**金色星图**（目标轨迹）；
- **符环**转速各不相同，分**顺行/逆行**；
- 拖动**星辉**滑块控制符环大小，拖动**转盘**控制方位（滚轮微调、双击归零）；
- 重合度 ≥ 90 点亮星座（≥95 两星、≥98 三星）；**缓速/凝神**辅助对准，卡关可**跳过**；
- **共鸣探测**（每关 2 次）提示某符环该有的强度与方位。

## 藏起来的数学

| 玩家看到的 | 实际是 |
| --- | --- |
| 符环转速（顺/逆、缓/疾/骤/迅） | 谐波频率 k = ±1…±4 |
| 星辉滑块 | 傅立叶系数幅度 |
| 方位转盘 | 傅立叶系数相位 |
| 星核定位 | 直流分量 a₀ |
| 共鸣探测 | 单频 DFT |
| 目标星图 | 目标曲线 DFT 截断到 ±4 次谐波后的重建（保证满分可达成） |
| 重合度评分 | 双向轨迹平均距离 |

进度存于 localStorage（键 `epicycle-progress`），清除即可重玩。
