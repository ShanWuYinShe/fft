# 镇澜 · 涌律守护

一款把**傅立叶变换的核心思想**藏进塔防玩法里的网页游戏（Vite + TypeScript，无框架、零依赖资源）。全程没有任何数学词汇——玩家看到的只是"数花瓣、配塔色"。

## 开发与运行

```bash
npm install     # 安装依赖（vite + typescript）
npm run dev     # 开发服务器
npm run build   # tsc 类型检查 + 构建到 dist/
npm run preview # 预览构建产物
```

## 玩法

- 乱流（敌人）沿水道涌向静心湖，周身花影的**瓣数各不相同**（1~4 瓣）；
- 底部卡槽有四种**音叉塔**，卡面花影瓣数与敌人一一对应；
- **只有同瓣数的音叉塔**能削平对应涌灵——异频的净波会直接穿过、毫无作用；
- 涌灵的血就是波的振幅：被打一下，花影就矮一分；
- 精英涌灵身负**多层花影**（多个频率的叠加），要几座塔协力逐层剥平；
- 变奏灵行进中会**切换瓣数**；终章 Boss「百澜」身负全部四道瓣影；
- 波次预告、提前唤醒换潮珠、×2 加速、星级（按剩余平静度）、无尽冲分模式。

## 藏起来的数学

| 游戏语言 | 傅立叶本质 |
| --- | --- |
| 花影瓣数（缓/行/疾/骤） | 频率 k = 1…4 |
| 同频才可作用，异频穿过 | 频率分量的正交独立性 |
| 血条 = 花影振幅 | 幅度 |
| 多层花影精英/Boss | 信号 = 多个频率分量之和；逐层剥平 = 分解 |
| 变奏灵 | 时变频率的信号 |
| 音效音高随瓣数升高 | 谐波列（k=1..4 恰为 C3 C4 G4 C5） |

## 结构

- `src/defs.ts` —— 频率、塔、敌人原型与经济数值
- `src/levels.ts` —— 四章八关的路径/波次表与无尽波次生成器
- `src/state.ts` —— 战斗模拟（波次状态机、追踪弹、经济、胜负）
- `src/render.ts` —— 战场渲染（花影、水道、弹道、粒子）
- `src/ui.ts` / `src/main.ts` —— DOM 界面与装配

进度存于 localStorage（键 `wave-warden-progress`），清除即重置。
